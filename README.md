## 🚀 Projects

- **Nutri Mithu (Flutter App)**  
  Redesigned a cross-platform mobile application with animated UI and Firebase Firestore integration for user data and nutrition tracking.

- **Music-Reactive LED System**  
  Developed a real-time IoT system using an ESP32, Python UDP server, and React frontend to sync LED patterns to audio beats.

- **ROS 2 Robot URDF Simulation**  
  Created a URDF robot model using Xacro, integrated it with ROS 2 Jazzy, and built a Python node for real-time collision avoidance. Simulated in RViz and Gazebo.

- **Autonomous Collaborative Terrain Mapping**  
  Design a multi-robot system where scout robots use LiDAR and odometry for 2D mapping and a coordinator robot fuses the data into a global map using UDP/Wi-Fi.

- **Flutter App**  
  Developed multiple mobile applications using Flutter framework with integrated state management and backend services.

- **React Web App**  
  Built web applications with a React frontend and Node.js/Express backend using REST APIs and MySQL integration.

- **Java Game – MysticMayhem**  
  Contributed to developing a simple 2D game in Java featuring player movement, basic combat, and collectible mechanics.

- **Nano Processor (VHDL)**
